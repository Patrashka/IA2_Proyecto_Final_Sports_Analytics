# IA2_Proyecto_Final_Sports_Analytics
Pipeline de visión artificial en Python que automatiza la detección en tiempo real de jugadores y el balón mediante YOLOv8 en videos aéreos del Campus UDEM. El sistema calcula centroides y evalúa la lógica espacial de la cancha para inyectar analíticas visuales y conteos dinámicos en el video de salida.
